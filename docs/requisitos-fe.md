# Projeto MeuNegocio360 - Documento de Requisitos (Frontend)

## Frontend

- Stack utilizada: React JS com Vite
- Paleta de cores: devem ser definidos como estilos globais da aplicação.
    - Laranja: #EC4E26 (botões primários, barra de navegação e texto de botões onHover e secondários);
    - Creme: #FCF5F0 (fundo das páginas);
    - Cinza: #4A3F39 (linha das tabelas, bordas dos cartões e texto secundário);
    - Preto: #1F1612 (texto principal);
    - Laranja amarronzado: #CDBBAE (rodapé);
- Fonte:
    - Barlow Condensed (pesos 500, 600 e 700): para títulos.
    - Barlow (pesos 400, 500 e 600): para textos, tabelas e rodapés.
